# Bhumi-Drishti-CubeSat
Plain HTML, CSS and JavaScript. No build step, no frameworks.

Files (keep in one folder):

index.html, people.html
style.css, script.js
Club_logo.png
assets/members/ (member photos, e.g. ishika.jpg, swagat.jpeg)
assets/cvs/ (CV PDFs, e.g. ishika-cv.pdf)
Copy assets/ from your existing repo using the same file names. If a photo is missing, the member's initials are shown instead.

Deploy: push to a GitHub repo, then Settings > Pages > deploy from branch (root). The only external resource is Google Fonts; if it is blocked, the site falls back to Georgia and system fonts.
